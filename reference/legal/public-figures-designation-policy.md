# 공인 선수 지정 기준 및 명단 운영 기준

본 문서는 사이트 공개 대상 선수를 공적 인물성 범위로 한정하기 위한 내부 운영 기준입니다.

## 1. 지정 기준

아래 기준을 모두 충족해야 공개 대상(`active`)으로 지정합니다.

1. 만 18세 이상(출생연도 기준, 경계 사례 제외)
2. 다음 중 1개 이상 충족
   - 국가대표 선발 이력(시즌 선발대회 상위 8위 이내)
   - 국제대회 국가대표 출전 이력
   - 실업팀 소속 현역
3. 언론 실명 보도 이력 존재

하나라도 애매하면 지정하지 않습니다.

## 2. 명단 데이터 소스

명단은 `data/public_figures.csv`를 단일 소스로 수동 관리합니다.

- 컬럼: `idNo, 이름, 슬러그, 출생연도, 지정근거, 언론보도URL, 지정일자, 상태`
- 상태값: `active`, `removed`
- 자동 판정 로직은 사용하지 않습니다.

`언론보도URL`은 대한체육회/대한빙상경기연맹 등 공식 발표 링크만 사용합니다.

## 3. 슬러그 규칙

- 로마자 표기, 소문자, 하이픈만 사용합니다.
- 동명이인은 소속 또는 출생연도 접미사를 사용해 충돌을 방지합니다. (예: `kim-minji-2007`)
- URL에는 `idNo`를 노출하지 않습니다.
- 슬러그는 공개 URL 식별자이므로 변경하지 않습니다.

## 4. 제외 요청 처리

본인 요청이 확인되면 지정 근거와 무관하게 요청을 우선합니다.

1. `data/public_figures.csv`에서 대상 선수 `상태=removed` 처리
2. `python build_data.py && python build_site.py` 재생성으로 공개 페이지/목록/사이트맵 제외
3. 검색엔진 색인 삭제 요청 진행

## 5. 운영 메모

- 지정 근거, 언론보도 URL, 지정일자를 누락하지 않습니다.
- 정책 변경 시 본 문서와 `reference/legal/privacy-request-procedure.md`를 같은 배포에서 함께 갱신합니다.
- 데이터 커밋 범위/익명화 규칙은 `reference/legal/anonymized-data-commit-policy.md`를 기준으로 운영합니다.
