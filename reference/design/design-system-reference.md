# 국가대표 유년기 페이지 디자인 시스템 레퍼런스

기준 소스: [build_site.py](../../build_site.py)

이 문서는 현재 정적 페이지 스타일을 재사용/확장할 때 필요한 디자인 토큰과 컴포넌트 규칙을 정리한 문서다.
값은 코드에 있는 실제 CSS/JS를 기준으로 작성했다.

## 1) 디자인 방향

- 톤: 신뢰감 있는 데이터 카드형 UI
- 키워드: 명확함, 중립성, 가독성, 낮은 인지부하
- 컨셉: "기사형 설명 + 대시보드형 요약"의 중간 지점

## 2) 컬러 토큰

### 기본 배경/서피스

- 앱 배경: `#F3F5F8`
- 카드/섹션 기본: `#FFFFFF`
- 보조 서피스: `#FAFBFC`
- 안내 박스 배경: `#F5F7FA`
- 보조 배경(배지 등): `#E4EBFF`

### 텍스트

- 본문 핵심: `#17181C`
- 보조 본문: `#3A3D45`
- 서브텍스트: `#5B5F68`
- 약한 텍스트: `#6B6F78`, `#8A8F99`, `#9BA0AA`, `#A9AEB8`, `#B4B9C2`

### 브랜드/강조

- Primary: `#2E63F6`
- Primary Hover: `#1B47C4`
- 그래프 보조선/점: `#B9CCFB`, `#C6CBD4`, `#DFE3E9`, `#E3E7ED`

## 3) 타이포그래피

### 폰트

- 기본: `Pretendard Variable`, `Pretendard`
- 폴백: `-apple-system`, `BlinkMacSystemFont`, `Apple SD Gothic Neo`, `sans-serif`

### 타입 스케일(주요 값)

- Hero H1: `34px`, `font-weight: 800`, `line-height: 1.32`, `letter-spacing: -0.03em`
- 섹션 제목 H2: `20px`, `font-weight: 800`, `letter-spacing: -0.02em`
- 본문/설명: `14.5px` ~ `16px`
- 메트릭 숫자: `26px`, `font-weight: 800`
- 캡션/보조: `11.5px` ~ `13.5px`

## 4) 레이아웃 시스템

- 메인 컨테이너 폭: `max-width: 700px`
- 좌우 패딩: `18px` (모바일 `14px`)
- 페이지 하단 패딩: `72px`
- 전역 섹션 간격: `gap: 14px`
- 기본 줄간격: `line-height: 1.6`

## 5) 라운드/보더/스페이싱

- 섹션 카드 반경: `22px`
- 메트릭 카드 반경: `18px`
- 보조 카드 반경: `16px`
- 작은 배지 반경: `999px` (pill)
- 구분선: `#F0F2F5` 1px 중심

## 6) 컴포넌트 규칙

### 6.1 Hero

- 배지 + 제목 + 소개문 3단 구성
- 소개문은 한 문장, 핵심어만 `font-weight: 700`으로 강조

### 6.2 Metrics Grid

- 2열 그리드
- 각 카드: 큰 숫자 + 짧은 라벨
- 숫자는 정량 정보, 라벨은 해석 없는 명사형

### 6.3 요약 리스트

- 번호 배지(1~3) + 한 줄 메시지
- 메시지는 길어져도 문장 1개 유지

### 6.4 읽는 법 박스

- 아이콘(점/선) + 설명 텍스트
- 설명 순서: 좋은 신호 -> 나쁜 신호 -> 결측 의미

### 6.5 나이별 카드(미니 차트)

- 카드 헤더: 이름 + 출생년도
- 서브라인: 요약 카피
- 차트 캔버스: `viewBox 0 0 300 92`
- 축 라벨: `7살 / 12살 / 18살`

### 6.6 초등부 분포 막대

- 좌측: 순위 번호/선수명/출전수
- 우측: `최고-중앙값-최저` 문장
- 막대: 파란색(일반), 회색(표본 적음)
- 중앙값: 흰색 세로선으로 표현

### 6.7 선수 상세 아코디언

- 행 클릭 시 펼침/접기
- 헤더: 이름 + 소속/첫 대회 + 상태(펼치기/접기)
- 본문: 연도/나이/등수 리스트

### 6.8 데이터 한계 카드

- Q/A 카드 반복 구조
- 질문은 볼드, 답변은 중립 톤

## 7) 데이터 시각화 규칙(JS)

### 나이별 점 그래프

- 상수
  - `CAP = 40`
  - `W = 300`
  - `TOP = 10`
  - `BOT = 64`
- y축 스케일: 루트 스케일
  - `y = TOP + sqrt((rank-1)/(CAP-1)) * (BOT-TOP)`
- 점 스타일
  - 1~2등: 파란 점 `#2E63F6`
  - 그 외: 회색 점 `#C6CBD4`
- 결측값: 하단 짧은 세로선 표시

### 초등부 범위 바

- 기준 범위: 1~40등
- 위치 계산
  - `left = (best - 1) / 40 * 100`
  - `width = max((worst - best) / 40 * 100, 2)`
  - `mid = min((median - 1) / 40 * 100, 98)`

## 8) 반응형 규칙

- 브레이크포인트: `max-width: 640px`
- H1 크기 축소: `34px -> 31px`
- 컨테이너 패딩 축소: `18px -> 14px`

## 9) 접근성/사용성 체크

- 인터랙션은 hover에만 의존하지 않고 텍스트 상태를 함께 제공한다.
- 색만으로 의미를 전달하는 요소에는 설명 텍스트를 반드시 동반한다.
- 결측 데이터는 "빈칸" 대신 시각적 패턴/문구로 명시한다.

## 10) 확장 시 지켜야 할 것

- 토큰 값을 하드코딩으로 추가하기보다 기존 팔레트에서 우선 선택한다.
- 새 컴포넌트도 "숫자 + 짧은 해석" 구조를 기본으로 유지한다.
- 분석 해석 문구를 늘릴 때는 [writing-style-reference.md](writing-style-reference.md) 기준을 따른다.
