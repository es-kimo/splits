## B. 제품 결정

### 1) 본체 한 문장

**초등 시기의 기록 위치는 이후 단계 도달과 관련은 보이지만, 아이의 진로를 단정할 정도의 예측력은 아닙니다.**

- 채택 근거: 이슈 7에서 백분위 기반 지표가 향상속도 지표보다 일관되게 높은 AUC를 보였지만, 인과 단정이 가능한 수준의 예측 모델은 아닙니다.
- 적용 원칙: 결과가 밋밋해 보여도 표현을 부풀리지 않습니다.

### 2) 훅→본체 연결 지점(화면 명세)

현재 `web/src/components/DistributionTool.tsx` 결과 카드 구조(`dist-verdict`, `dist-verdict-detail`)를 기준으로 아래 3개 출력을 순서대로 배치합니다.

1. **출력1(위치)**: 기존 결론 문구 유지  
   예: `또래 47명 중 상위 60%예요`
2. **출력2(향상)**: 전년 대비 변화 + 또래 평균 변화  
   예: `작년보다 3.2초 향상 · 또래 평균 2.1초 향상`
3. **출력3(본체 링크)**: `초등 성적과 이후 진로에 대해 알아보기` 링크 버튼 (`/analysis/`)

세부 규칙:

- 개인 화면에는 지속률/이탈률/진로 확률을 퍼센트로 노출하지 않습니다.
- 출력2는 전년 기록 입력이 없거나 비교 가능한 또래 표본이 부족하면 숨기고, 대체 안내 문구만 보여줍니다.
- 출력3은 결과 카드가 열린 상태에서 항상 동일 위치에 노출해 읽는 흐름을 고정합니다.

### 3) 종목 확장 시점

#### 쇼트트랙 본체 완성 조건

- `findings.md` 확정 + 훅→본체 명세 반영 + 신뢰 한계 문구 고정
- 개인 화면 확률 비노출 규칙 QA 완료

#### 스피드 적용 시 추가 작업

- 분포/향상/도달 지표를 `classCd=1` 기준으로 별도 산출
- 쇼트트랙과 스피드를 같은 문장으로 섞지 않도록 UI 분리
- 표본 부족 구간의 비공개 처리 기준(k-익명성) 재검증

#### 타 종목 확장 판단 기준

- 동일 구조 데이터(기록·학년·성별·거리)를 안정적으로 수집 가능할 것
- 단계 도달 지표 대상 N이 해석 가능한 수준을 확보할 것
- 신뢰 한계 문구를 사용자 화면에 독립적으로 설명할 수 있을 것

### 4) 외부 협의 시점 판단

- 연맹·체육회 접근은 아래 3개가 충족된 뒤 진행합니다.
  1. 검증 결과 문서 확정
  2. 개인 화면 비오해 가드레일(확률 비노출, 한계 문구) 반영
  3. 후속 구현 이슈의 최소 1차 반영 완료
- 첫 문장(초안):  
  `공개 경기기록 기반으로 유년기 기록의 분포와 해석 한계를 정리했으며, 개인 예측이 아닌 집단 경향 안내 원칙으로 서비스를 설계하고 있습니다.`

## C. 신뢰 한계 명시 문구(확정안)

1. **병합 오류율**: 식별키 감사에서 합쳐짐 의심 비율이 11.0%로 관측돼 개인 단위 추정에는 오차 위험이 남아 있습니다.
2. **관측기간 제약**: 최신 학년 구간은 관측기간 부족으로 이탈률이 과대 추정될 수 있습니다.
3. **기록 중단≠은퇴**: `n시즌 미출전`은 기록 중단 판정 기준이며, 실제 은퇴를 뜻하지 않습니다.
4. **생월 효과 미통제**: 이슈 #86 점검에서 `INF503` 최종등록정보(캐시 2,639건)가 `출생년도(YYYY년)`만 제공하는 것으로 확인돼 같은 학년 내 상대연령(생월) 차이를 현재 통제할 수 없습니다.

## D. 이탈률 콘텐츠 배치 원칙

| 대상 | 읽히는 방식 |
| --- | --- |
| 학부모 개인 화면 | "우리 애도 곧 그만두겠구나"로 오해될 가능성이 큽니다. |
| 집단 콘텐츠·정책 자료 | "어느 구간에서 왜 빠져나가는가"를 묻는 진단 자료로 읽힙니다. |

따라서 이탈률·지속률은 집단 콘텐츠 페이지에서만 다루고, 개인 화면에는 배치하지 않습니다.
