# 스플릿 브랜드 기준 (Issue #60)

이 문서는 사이트 전반에 적용하는 브랜드 아이덴티티 기준입니다.  
마일스톤 안에서는 아래 기준을 다시 바꾸지 않습니다.

## 1) 이름/표기

- 서비스명: **스플릿**
- 영문 `splits`는 도메인/코드/파일명에서만 사용합니다.
- 사용자 화면 로고·헤더·OG는 한글 `스플릿`을 기본으로 사용합니다.

## 2) 로고

- 심볼은 갈라진 두 면(좌 27, 우 29, 간격 8) 비율을 유지합니다.
- 가로형 로고(심볼 + 워드마크)를 기본으로 사용합니다.
- 상단 헤더에서는 심볼 + `스플릿` 워드마크를 고정 사용합니다.

## 3) 색상 토큰

- Primary: `#2E63F6`
- Primary (dark): `#6D95F9`
- Ink: `#17181C`
- 배경: `#F3F5F8`
- 카드: `#FFFFFF`
- 보조 표면: `#FAFBFC`, `#F5F7FA`
- 경계선: `#F0F2F5`

원칙:
- 파랑은 핵심 상태/데이터 강조에만 사용합니다.
- 선택 상태(탭/칩/주요 CTA)는 Ink(`#17181C`) 우선으로 맞춥니다.
- 데이터 분류 의미를 색상 다변화로 만들지 않습니다.

## 4) UI 원칙

- 모바일 기준 레이아웃을 우선합니다.
- 카드 반경은 16~22px 범위를 유지합니다.
- 버튼/칩 최소 높이는 44px 이상을 유지합니다.
- 분포 페이지는 `조건 선택 → 입력 → 위치 결론` 2단계 흐름을 유지합니다.

## 5) OG/파비콘

- 파비콘: `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`
- OG: `og-default.png`, `og-player.png`, `og-competition.png`, `og-distribution.png`
- OG는 1200x630 고정 다크 배경을 사용하고 절대 URL로 노출합니다.
- 동적 OG 생성은 사용하지 않습니다.

## 6) 문구 톤

- 안내/인터랙션: `~요`
- 데이터 기준/한계: `~습니다`
- 내부 구현 용어(파일명/컬럼명)는 화면 문구로 노출하지 않습니다.
