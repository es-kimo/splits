# ADR 0016 — 히트 몬테카를로 시뮬레이션 (R-14)

- 상태: Accepted
- 작성일: 2026-09-07
- 선행: `docs/adr/0015-api-boundary.md`

## 문맥

한 히트에 함께 배정될 선수와 진출 인원을 사용자가 정하면, 가능한 조합을
정적으로 미리 생성할 수 없습니다. R-13의 완료된 레이팅 실행을 고정해 조회하는
짧은 계산 경로가 필요합니다.

## 결정

1. 각 선수의 경기 성능은 `Normal(mu, sqrt(sigma² + beta²))`에서 표본을 뽑습니다.
   `sigma`는 선수별 추정 불확실성이고 `beta`는 모든 선수에 공통인 경기 내
   변동입니다. 두 값은 서로 대체하지 않습니다.
2. 페널티는 초기에는 독립·동일 확률로 표본화합니다. 요청에서 비율을 지정하지
   않으면 R-02 원천 결과의 상태를 정규화한 뒤 `PEN` 비율을 사용합니다. 원천
   결과가 없을 때는 상태가 보존된 레저를 대체 입력으로 사용하며, 둘 다 없으면
   숫자를 임의로 채우지 않고 시뮬레이션 요청을 거부합니다.
3. 결과는 Wilson 95% 구간과 실제 반복 횟수를 함께 반환합니다. 모든 선수의 구간
   폭이 2%p 이하가 되면 멈추고, 최대 50,000회 또는 1초에 도달하면 미수렴 상태와
   현재 구간을 반환합니다.
4. 공개 API는 불투명 선수 ID만 받습니다. 명시 레이팅은 Python API와 테스트에만
   허용하며, 내부 선수 식별자는 응답에 포함하지 않습니다.
5. 캐시는 입력 순서와 무관한 반올림 `(mu, sigma)` 목록, 진출 인원, 페널티율,
   `beta`, 실행 ID, seed, 모델 버전을 키로 한 프로세스 로컬 1시간 TTL/LRU입니다.
   seed를 키에 포함해 결정적 요청의 의미를 보존합니다.
6. 가용성 방어로 프로세스별 IP당 분당 20회 제한을 두고, 계산 예산 상한을
   강제합니다. 다중 인스턴스 전체 한도는 배포 계층 rate limiter의 책임입니다.
7. 1:1에 적합한 Platt 보정기는 다인 히트의 선수별 진출 확률에 적용하지 않습니다.
   독립 변환은 한 히트의 고정 진출 인원 제약을 보존하지 않기 때문입니다.

## 검증과 보정

`python -m server.simulate --calibrate --holdout`는 마지막 시즌들을 홀드아웃으로
분리합니다. 모델은 해당 결과를 갱신하기 전에 각 히트를 예측하고, 같은 대회·종목·
부문에서 확인되는 다음 라운드 참가 여부만 실제 진출 라벨로 사용합니다. 다음
라운드를 확인할 수 없는 히트는 평가에서 제외합니다.

리포트는 원시 히트 확률과 pairwise Platt 보정 전이값을 함께 측정하지만, 후자는
참조값일 뿐 표시값으로 채택하지 않습니다. 별도 보정을 도입하려면 홀드아웃 개선
근거와 진출 인원 합을 보존하는 변환을 함께 제시해야 합니다.

## 결과

- API 프로세스는 레이팅 상태를 변경하지 않고 시작 시 고정한 실행만 읽습니다.
- 요청별 난수는 전역 RNG를 사용하지 않으므로 같은 입력과 seed는 같은 결과를
  냅니다.
- R-02 상태 정보가 보존되지 않은 공개 익명 데이터만으로는 기본 페널티율을
  산정할 수 없습니다. 운영 환경은 비공개 원천 결과 경로 또는 별도 상태 레저
  경로를 제공해야 합니다.
