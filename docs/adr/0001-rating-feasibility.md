# ADR 0001 — 레이팅 성립 가능성 판정 (R-01)

- 상태: Accepted
- 작성시각: 2026-08-29T11:53:29
- 입력: `data/records_anon.csv`

## 문맥

- 선수 레이팅은 비교 그래프가 연결되어 있어야만 의미를 가집니다.
- 본 ADR은 완주자 대결 하한 그래프를 기준으로, 현재 데이터에서 레이팅을 진행할지 중단할지 판정합니다.

## 판정 규칙

| 조건 | 판정 |
| --- | --- |
| 각 성별 내부 거대 성분 ≥ 90% AND 핵심 단계 전이 공유 선수 최소값 ≥ 10 | GO |
| 성별 내부 거대 성분 70~90% | 조건부 GO |
| 성별 내부 거대 성분 < 70% | STOP |

## 관측값

- 전체 그래프 거대 성분 비율: **53.70%**
- 성별=남 거대 성분 비율: **90.29%** (성분수=20)
- 성별=여 거대 성분 비율: **94.75%** (성분수=10)
- 비교 가능한 (시즌,부문,성별) 셀 수: **328**
- 양방향 비교 가능한 (시즌,부문,성별) 셀 수: **310**
- 고립 (시즌,부문,성별) 셀 수: **11**
- 핵심 단계 전이 공유 선수 최소값: **176**
- 고립 셀 소속 선수 비율: **3.61%**
- 성별 미상/기타 노드 수: **11**

## 결정

- 최종 결론: **GO**
- 근거: 남/여 각 성별 내부 거대 성분 비율이 90% 이상이고, 핵심 단계 전이(초등→중등→고등→대학·일반)의 공유 선수 최소값이 10명 이상입니다.
- 판정 안정성 메모: 남 성별 거대 성분은 1,227/1,359 (90.29%)이고, 90% 기준 하락 여유는 4명입니다.
- 1차 실행은 STOP 판정이었지만, 원인은 데이터 훼손이 아니라 명세 결함 두 가지로 확인되었습니다.
- 명세 결함: (1) 성별 분리 없이 전역 연결성을 측정함 (2) 부문 라벨(`5,6`)을 학년 산술 전이로 취급해 종적 다리를 측정하지 못함.
- 이는 사후 기준 완화가 아니라 측정 방식 수정이며, 두 실행의 기저 그래프는 동일합니다 (노드 2,285, 엣지 46,475).
- 후속 지침: 전역 레이팅 계산 구현(R-02+)로 진행합니다.
