# ADR 0015 — 개인 기록 매칭과 재식별 방어 (R-15)

- 상태: Rejected
- 작성일: 2026-09-07
- 선행: `docs/adr/0015-api-boundary.md`

## 문맥

익명 경기 데이터의 개인 레코드를 경기 결과 입력으로 찾고, 성공하면 불투명 세션 토큰으로 개인 레이팅을 조회하는 기능을 검토했습니다. 이 기능은 학부모가 자녀 기록을 찾는 데 쓸 수 있지만, 공개 경기 결과를 가진 제3자에게도 같은 경로를 제공합니다.

위험 평가에서 서로 다른 세 대회의 대회·거리·기록을 교차한 1,420명 전원이 단일 후보가 되었고, 순위만 사용해도 1,443명 중 1,030명(71.38%)이 단일 후보가 되었습니다. 자세한 방법과 한계는 `docs/privacy/reidentification_assessment.md`에 기록합니다.

## 결정

1. `POST /v1/match`를 만들지 않습니다.
2. 개인 매칭용 세션 토큰과 후속 개인 조회 경로를 만들지 않습니다.
3. 브라우저에 코호트 데이터나 매칭 인덱스를 내려주는 클라이언트 매칭도 만들지 않습니다.
4. 공개 API는 기존의 불투명 ID를 이미 알고 있는 공인 선수 조회와 히트 시뮬레이션 범위로 유지합니다.

기존 불투명 ID는 응답에서 내부 선수 식별자를 숨기는 경계일 뿐, 공개 결과를 입력으로 받는 재식별 공격을 방지하는 수단이 아닙니다.

## 고려한 통제와 기각 근거

서로 다른 세 대회 증거, 중간 후보 k=10 하한, 후보 수 비노출, 일정한 실패 응답, 응답 시간 평준화, IP·토큰별 제한, 24시간 토큰, 입력과 내부 식별자를 잇지 않는 로그를 검토했습니다. 이 통제는 무작위 열거의 비용은 높일 수 있으나, 세 공개 결과를 이미 아는 표적 공격자가 한 번의 완성 요청으로 성공하는 것을 막지 못합니다.

점 추정 대신 구간만 반환해도 매칭 성공으로 생긴 인물-익명 레코드 연결은 되돌릴 수 없습니다. 대상 다수가 미성년자이므로 이 잔여 위험을 수용하지 않습니다.

## 결과

- 개인 기록을 입력받아 개인 레이팅이나 익명 레코드를 반환하는 공개 기능은 제공하지 않습니다.
- 삭제·처리정지 요청에는 매칭 세션이나 토큰을 철회할 별도 경로가 없습니다. 재도입을 검토한다면 승인 목록을 후보 계산보다 먼저 적용하고 배포 완료를 확인해야 합니다.
- 재검토에는 독립적인 재식별 평가, 삭제 제외 검증, 사람의 개인정보 검토와 명시적 승인이 필요합니다. 단순한 속도 제한이나 토큰 수명 설정만으로는 충분하지 않습니다.
